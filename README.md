# ProjectSphere

ProjectSphere is a MERN stack web application designed to showcase undergraduate student projects. The system allows students to submit their individual project details, lecturers/admins to manage project records, and recruiters to browse approved projects after logging in.

## Project Overview

ProjectSphere provides a centralized platform for undergraduate students to present their academic projects in a structured and professional way. Each project can include important information such as the title, description, technology stack, diagrams, and database schema.

## Technology Stack

This project uses the MERN stack:

* **MongoDB** - Database
* **Express.js** - Backend framework
* **React.js** - Frontend library
* **Node.js** - Runtime environment

Additional tools:

* **Vite** - React development build tool
* **GitHub** - Version control and collaboration
* **GitHub Desktop** - Git workflow management
* **VS Code** - Development environment

## Main Users

* Students
* Recruiters
* Lecturers
* Admins

## Main Features

### Student Features

* Student registration and login
* Submit individual project details
* Add project title, description, technology stack, diagrams, and database schema
* View submitted projects
* Edit or delete own project records

### Recruiter Features

* Recruiter login
* Browse approved student projects
* View project details
* Add comments on projects

### Lecturer/Admin Features

* Manage users
* Review student project submissions
* View project details
* Manage project records
* Monitor create and delete events

### Notification Features

* Notifications for project creation events
* Notifications for project deletion events
